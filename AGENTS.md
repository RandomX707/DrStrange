# SIGNOVA project instructions

- All source code must be original.
- Do not clone, copy, fetch, or vendor the ULTRON reference repository.
- Use official library documentation and independently written implementations.
- Do not invent benchmarks, model weights, accuracy scores, datasets, or successful tests.
- Distinguish observed evidence from assumptions.
- Never claim that fingerspelling recognition is continuous sign-language translation.
- Prefer straightforward architecture and minimal dependencies.
- Do not introduce Docker, a database, or cloud infrastructure without demonstrated need.
- Use pinned dependencies where reproducibility requires them.
- Do not modify unrelated files.
- Do not commit or push unless explicitly instructed.
- Never bypass sandbox permissions or alter host security settings.
- Document blocked verification explicitly.
- Complete only the authorized phase.

Current scope: Phase 1A camera and hand-landmark foundation only. No recognition,
training, filtering, custom tracking identities, enhancement, or translation UI.
